I was reading Peter Shirley's little book [[http://in1weekend.blogspot.com/2016/01/ray-tracing-in-one-weekend.html][Ray Tracing in One Weekend]] which provides code in C and for fun wanted to try to implement it in [[https://reasonml.github.io/][Reason]]. Source code is [[https://github.com/wtfleming/reason-examples/tree/master/ray-tracer][available here]].

Above is a pregenerated image, but you can click the button below to generate a smaller lower quality picture on demand (it takes about 5 seconds to generate on my laptop).
